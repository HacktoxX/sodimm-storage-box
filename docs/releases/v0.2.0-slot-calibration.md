This release provides the first printable fit-calibration models for the
parametric SO-DIMM storage-box project. It does not contain the final 20-slot
box.

## Included models

- **sodimm-slot-test.stl** — one compact 2 × 2 calibration body using the
  standard 1.0 mm total thickness clearance.
- **sodimm-slot-variants.stl** — three separated bodies engraved 0.8, 1.0, and
  1.2 for direct clearance comparison.

## Print guidance

- Material: PETG.
- Nozzle: 0.4 mm.
- Layer height: 0.20 mm.
- Orientation: upright as exported.
- Supports: none.

The models are intended for a short fit-validation print before the complete
storage box is developed.

## Fit validation

Use the thickest SO-DIMMs that will be stored. Insert only unpowered modules,
hold them by the PCB edges, and never force them into a slot. Confirm that:

- the module enters through the chamfer without catching;
- the PCB does not bow or become side-clamped;
- the contact edge remains clear of the relieved floor;
- the module has little play but can be removed comfortably.

When printing the variant asset, select the smallest engraved clearance that
inserts and releases reliably on the target printer and PETG profile.

## Reproducing the assets

From the repository root:

```bash
scripts/export_all.sh
```

The command creates both attached STL files under `exports/calibration/`
without modifying any OpenSCAD source parameter.
